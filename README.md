# Aidin Givtaj

A single-page portfolio for GitHub Pages. Open `index.html` directly or run `python3 -m http.server 8000 --bind 127.0.0.1` from this folder. There is no build step.

Edit the copy in `index.html` and the layout in `styles.css`. The introduction, project descriptions, and technology list follow the [GitHub profile README](https://github.com/givtaj/givtaj).

For GitHub Pages, use the root of the `main` branch of `givtaj/givtaj.github.io` as the publishing source.

The featured artwork and save-flow screenshot come from [Daedlo](https://daedlo.com/) and [SeeRunTime](https://seeruntime.com/). The portrait is the public GitHub avatar. Instrument Serif and Skill Icons license notices are included in `assets/`.
