# Aidin Givtaj

A single-page portfolio for GitHub Pages. Open `index.html` directly or run `python3 -m http.server 8000 --bind 127.0.0.1` from this folder. There is no build step.

Edit the copy in `index.html` and the layout in `styles.css`. The introduction and project descriptions follow the [GitHub profile README](https://github.com/givtaj/givtaj).

For GitHub Pages, use the root of the `main` branch of `givtaj/givtaj.github.io` as the publishing source.

The Daedlo artwork and save-flow screenshot come from [Daedlo](https://daedlo.com/). The SeeRunTime preview shows the [Rust/Tokio work-stealing lesson](https://seeruntime.com/#v=1&model=tokio&scenario=stealing&event=steal). The portrait is the public GitHub avatar. Instrument Serif and Skill Icons license notices are included in `assets/`.
